Q1. A university wants to develop a simple student registration system. When a student registers, the system collects 
their first name, last name, department, and registration ID. The system must process and display the student's 
information according to the following requirements.

Do the following:
1. Input the student's first name, last name, department name, and registration ID.
2. Calculate and display the number of characters in the student's first name and last name.
3. Copy the first name into a separate string variable called fullName.
4. Merge the first name and last name into fullName, separated by a space.
5. Append only the first 4 characters of the department name to a new string called profile.
6. Compare the entered department with "Computer Science". Display whether the student belongs to the Computer Science department.
7. Check whether the registration ID starts with "FA".
8. Find the position of the first occurrence of the character 'a' in the student's full name.
9. Search for the word "Science" in the department name. Display whether the word exists.


Q2. A teacher wants to save the class list to disk so it can be reused tomorrow. Input N (max 30) and N student
names. Write all names to student.txt, one per line. Close the file, reopen it in read mode and read the names back
into a second 2D array. Display each name with its length and find the longest name.
